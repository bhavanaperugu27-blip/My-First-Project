🍷 Wine Quality Prediction Using Machine Learning

📌 Project Overview

This project uses Machine Learning techniques to predict wine quality based on its physicochemical properties.

The model analyzes different features of wine and predicts its quality.

🎯 Objectives

- Understand and analyze the wine quality dataset.
- Perform Exploratory Data Analysis (EDA).
- Clean and preprocess the data.
- Train Machine Learning models.
- Evaluate model performance.

📊 Dataset Information

- Dataset: WineQT.csv
- Total Records: 1,143
- Features: 11 input features (excluding Id)
- Target: Quality
